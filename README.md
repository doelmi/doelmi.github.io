# Fahmi's Futuristic Hub

Proyek ini adalah landing page statis yang baru dibangun untuk menampilkan beberapa API lokal dan desain tema futuristik.

## Ringkasan

Halaman ini dibuat dengan HTML dan CSS murni. Desainnya berfokus pada tampilan modern dengan tema gelap, efek neon, dan kartu API interaktif.

## Struktur Proyek

- `index.html`
  - Landing page utama dengan hero section futuristik.
  - Menampilkan daftar API yang tersedia dalam desain kartu.
- `style.css`
  - Semua gaya halaman, termasuk animasi, layout, dan efek visual.
  - Menggunakan Font Google seperti `Orbitron` dan `Rajdhani`.
- `api/`
  - Folder berisi file JSON statis yang tersedia sebagai API.
  - `rainbow.json` - data JSON sederhana tentang warna pelangi.
  - `animals.json` - data statis hewan dengan nama dalam Bahasa Inggris, Bahasa Indonesia, dan nama latin.
  - `id_companies.json` - data statis perusahaan Indonesia yang baru ditambahkan.

## API yang Tersedia

- `api/rainbow.json`
  - API warna pelangi.
- `api/animals.json`
  - API data hewan statis.
  - Setiap item berisi `name_en`, `name_id`, dan `latin_name`.
- `api/id_companies.json`
  - API data perusahaan Indonesia.

## Fitur Utama

- Tampilan landing page futuristik dengan efek cahaya dan gradien.
- Kartu API responsif yang berubah saat hover.
- Daftar API mudah diakses melalui tautan di halaman utama.
- Komponen yang jelas dan mudah dikembangkan untuk menambah API baru.

## Cara Menggunakan

1. Buka `index.html` di browser.
2. Pilih salah satu API di halaman utama.
3. File JSON akan ditampilkan langsung sebagai data statis.

## Catatan

Proyek ini dikembangkan pada tahun 2026 dan merupakan halaman statis sederhana untuk menampilkan API lokal dan desain visual modern.
